# 🚫 Senpai Stream - Bypass Ad-Gate

Userscript ViolentMonkey/Tampermonkey qui bypass automatiquement le mur
publicitaire de **Senpai Stream**, sans regarder de publicité.

## ✅ Installation

1. Installe [ViolentMonkey](https://violentmonkey.github.io/) ou [Tampermonkey](https://www.tampermonkey.net/)
2. Clique ici → [**Installer le script**](./bypass-adgate.user.js)
3. Confirme l'installation

## ⚙️ Fonctionnement

- Fonctionne sur **senpaistream.to**
- Détecte automatiquement le bouton du mur publicitaire
- Intercepte le clic sur "Continuer" et **bloque la redirection** vers la pub
- Complète les étapes Livewire automatiquement
- Le film / épisode se lance directement ✅

## 🌐 Compatibilité

| Navigateur | Extension |
|---|---|
| Chrome / Edge | Tampermonkey ou ViolentMonkey |
| Firefox | Tampermonkey ou ViolentMonkey |
| Safari | Tampermonkey |
